# Cron & Automation

## Scheduled Jobs

```text
| Command                 | Description                                          |
| ----------------------- | ---------------------------------------------------- |
|   crontab -e            | Edits the current user's scheduled cron jobs.        |
|   crontab -l            | Lists the current user's cron jobs.                  |
|   crontab -r            | Removes the current user's cron jobs.                |
|   systemctl status cron | Checks the cron service status.                      |
|   at                    | Schedules a command to run once at a specified time. |
|   atq                   | Lists scheduled `at` jobs.                           |
|   atrm                  | Removes a scheduled `at` job.                        |

```
