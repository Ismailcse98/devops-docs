# Git for DevOps

## Essential Git Commands

```text
| Command                   | Description                                                      |
| ------------------------- | ---------------------------------------------------------------- |
|   git init                | Initializes a new Git repository.                                |
|   git clone URL           | Clones a remote repository.                                      |
|   git status              | Displays the current working tree status.                        |
|   git add .               | Adds changes to the staging area.                                |
|   git commit -m "message" | Creates a commit from staged changes.                            |
|   git log                 | Displays commit history.                                         |
|   git branch              | Lists Git branches.                                              |
|   git checkout -b branch     | Switches to another branch.                                      |
|   git switch branch       | Modern command for switching branches.                           |
|   git merge branch        | Merges another branch into the current branch.                   |
|   git pull                | Downloads and integrates remote changes.                         |
|   git push                | Uploads local commits to a remote repository.                    |
|   git fetch               | Downloads remote changes without merging them.                   |
|   git diff                | Displays differences between changes.                            |
|   git stash               | Temporarily stores uncommitted changes.                          |
|   git reset               | Resets commits or staging changes depending on the options used. |
|   git revert              | Creates a new commit that reverses an earlier commit.            |

```
