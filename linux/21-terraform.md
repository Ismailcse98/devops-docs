# Terraform

## Terraform Commands

```text
| Command                | Description                                                 |
| ---------------------- | ----------------------------------------------------------- |
|   terraform version    | Displays the installed Terraform version.                   |
|   terraform init       | Initializes a Terraform project and downloads providers.    |
|   terraform fmt        | Formats Terraform configuration files.                      |
|   terraform validate   | Validates Terraform configuration syntax and structure.     |
|   terraform plan       | Shows the infrastructure changes Terraform intends to make. |
|   terraform apply      | Applies Terraform infrastructure changes.                   |
|   terraform destroy    | Destroys infrastructure managed by Terraform.               |
|   terraform show       | Displays the current Terraform state or plan.               |
|   terraform output     | Displays Terraform output values.                           |
|   terraform state list | Lists resources tracked in the Terraform state.             |
|   terraform state show | Displays detailed state information for a resource.         |

```
