# Performance & Troubleshooting

## CPU/RAM/Disk Troubleshooting

```text
| Command        | Description                                               |
| -------------- | --------------------------------------------------------- |
|   top          | Identifies processes consuming CPU and memory.            |
|   htop         | Provides interactive process and resource monitoring.     |
|   free -h      | Checks RAM and Swap usage.                                |
|   df -h        | Checks filesystem disk usage.                             |
|   du -sh /*    | Helps identify directories consuming disk space.          |
|   iostat -xz 1 | Analyzes disk I/O performance and bottlenecks.            |
|   vmstat 1     | Monitors CPU, memory, and I/O activity in real time.      |
|   uptime       | Checks system load average and uptime.                    |
|   dmesg -T     | Investigates kernel and hardware-related issues.          |
|   lsof         | Shows open files and network resources used by processes. |

```
