# Repository Status & Information

## Check Repository Status
Shows modified files, staged files, untracked files, and the current branch.
```bash
git status
```

## Short Status
Displays repository status in a compact format.
```bash
git status --short
```

## Show Git Branches
Lists local branches and marks the currently checked-out branch.
```bash
git branch
```


## Show All Branches
Displays both local and remote-tracking branches.
```bash
git branch -a
```

## Show Remote Branches
Lists branches available from configured remote repositories.
```bash
git branch -r
```

## Show Repository Information
Displays configured remote repositories and their fetch/push URLs.
```bash
git remote -v
```

## Show Git Root Directory
Returns the root directory of the current Git repository.
```bash
git rev-parse --show-toplevel
```
